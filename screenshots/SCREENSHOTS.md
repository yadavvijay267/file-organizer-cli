# Screenshots

Add terminal screenshots here as you capture them:

- `demo-before-after.png` — the `--demo` run showing the messy folder
  before and after organising.
- `dry-run.png` — a `--dry-run` preview on a real folder.

`screenshots/demo-output.txt` already contains the plain-text output of a
real demo run — paste it into a terminal screenshot or keep it as the
text record.
